5-2 VSCodeでAIに伝わるプロンプトの書き方

プロンプトは、コード用／文章用／データ処理用で分ける

コード用
- 修正箇所の範囲を明示
- 目的を明示
- 想定する動作を明示
- テスト方法も合わせて依頼
例：
この関数の処理速度を改善したいです。入力と出力仕様は変えず、計算量を減らす方法でリファクタリングしてください。改善後の処理のテストコードも作成してください。


文章用
- 読者
- 使用シーン
- 文字数
- 禁止表現
- トーン
例：
営業部向けに、リスク説明の文章を500文字で作成。専門用語は控えめで、否定的な表現は禁止。

データ処理用
- 入力データの種類
- 出力形式
- 例外処理の基準
- エラー時の動作
例：
CSVの売上データを読込、商品カテゴリ別に合計値を出力。新しいカテゴリ名が含まれる場合は警告を表示。
