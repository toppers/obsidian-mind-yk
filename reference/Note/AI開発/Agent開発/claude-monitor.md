# claude-monitor

Claude Code の使用量をリアルタイム監視し、消費ペースから枯渇時刻を予測して警告する CLI。親リストは [[AIコーディングツール・知識グラフ・コードベース分析・リポジトリ管理ツールのリファレンスリスト]]。導入状況は [[uv-tool-3]]。

- [GitHub — Maciek-roboblog/Claude-Code-Usage-Monitor: Real-time Claude Code usage monitor with predictions and warnings](https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor)

```
uv tool run --from claude-monitor ccm
```
