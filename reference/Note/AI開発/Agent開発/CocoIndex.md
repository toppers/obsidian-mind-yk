# CocoIndex

多様なソースをライブで継続的に索引化し、AI エージェント向けのコンテキストを供給するインクリメンタルデータフレームワーク。コード検索特化版は [[cocoindex-code]]。親リストは [[AIコーディングツール・知識グラフ・コードベース分析・リポジトリ管理ツールのリファレンスリスト]]。

- [CocoIndexとは｜AIエージェント向けインクリメンタル処理OSSの仕組み \| 秋霜堂株式会社](https://syusodo.co.jp/tech-blog/articles/repo-cocoindex-io-cocoindex)
- Python(APIレイヤー)とRust(コアエンジン)
- Apache-2.0ライセンス
- 多様なソース(コードベース、議事録、メールボックス、Slack、PDF、動画)を「ライブで継続的にフレッシュなコンテキスト」へ変換
- 検索の種類
	- Semantic Search
		- ドキュメントの埋め込み、ベクタ保存、意味による返答
	- Multimodal Search
	- Structured Extraction
	- Knowledge Graphs
	- Ingest ＆Transform
- [CocoIndex — incremental data framework for AI agents](https://cocoindex.io/)
- [GitHub \- cocoindex\-io/cocoindex: Incremental engine for long horizon agents 🌟 Star if you like it\! · GitHub](https://github.com/cocoindex-io/cocoindex?utm_source=newsletter.theresanaiforthat.com&utm_medium=newsletter&utm_campaign=openai-sneaks-into-chrome&_bhlid=435925dc90c43eac4e8b9e6ab3454fcaf363184e)
	- codebase, meeing notes, inboxes, SLack, PDF, videos

		- npx skills add coconindex-io/cocoindex
