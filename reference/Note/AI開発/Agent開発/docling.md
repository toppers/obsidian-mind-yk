# docling

複合文書（PDF・Office・画像・音声ほか）を AI が扱える構造化データへ変換するツール。各種ファイルの Markdown 化については [[リポジトリのMarkDown化]] や [[MarkItDown]] も参照。親リストは [[AIコーディングツール・知識グラフ・コードベース分析・リポジトリ管理ツールのリファレンスリスト]]。

[Docling — Turn complex documents into structured data your AI can use](https://docling.ai/)
- PDF, DOCX, PPTX, XLSX, HTML, EPUB, Apple Pages, WAV, MP3, WebVTT, Box Notes, email formats (EML, MSG), images (PNG, TIFF, JPEG, ...), LaTeX,- DocLang, plain text, and more
- 📑 Advanced PDF understanding incl. page layout, reading order, table structure, code, formulas, image
