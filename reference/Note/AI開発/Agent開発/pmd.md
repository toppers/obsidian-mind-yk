[GitHub \- pmd/pmd: An extensible multilanguage static code analyzer\. · GitHub](https://github.com/pmd/pmd)
- An extensible multilanguage static code analyzer.
- 持続可能な多言語対応の静的コードアナライザー
- 未使用変数、空のcatchブロック、不要なオブジェクト作成など、一般的なプログラミング上の欠陥を検出
- ソースファイルを抽象構文木（AST）に解析し、ルールを適用して違反を検出
- サポート:Java、JavaScript、Salesforce.com ApexおよびVisualforce、Kotlin、Swift、Modelica、PL/SQL、Apache Velocity、JSP、WSDL、Maven POM、HTML、XML、XSL
- コピー＆ペースト検出ツールである**CPD**:
	- Coco、C/C++、C#、CSS、Dart、Fortran、Gherkin、Go、Groovy、HTML、Java、JavaScript、JSP、Julia、Kotlin、Lua、Matlab、Modelica、Objective-C、Perl、PHP、PL/SQL、Python、Ruby、Salesforce.com ApexおよびVisualforce、Scala、Swift、T-SQL、Typescript、Apache Velocity、WSDL、XML、XSL
- インストール
	- リリースページから最新のバイナリzipファイルをダウンロードし 、任意の場所に解凍
	- [Release PMD 7\.27\.0 \(28\-August\-2026\) · pmd/pmd · GitHub](https://github.com/pmd/pmd/releases/tag/pmd_releases/7.27.0)
