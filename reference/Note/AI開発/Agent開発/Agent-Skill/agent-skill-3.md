1. **引数（位置）**
   - 見出しに「必須第１引数」等があれば `Clix` の positional として表にする
   - `choices` が req にある場合は `choices` として表へ反映
2. **引数（オプション）**
   - `--name` / `--user` 等の項目について、型、デフォルト、説明、動作を `Clix` の表に反映
3. **無視規則**
   - 「`latest10` の場合は ... 無視」のような条件分岐は、対応する外部仕様の「動作」へ必ず書く
4. **出力形式**
   - 「既定は名前のみ JSON」「--all で全項目 JSON」など、stdout の契約を仕様化
5. **エラー規則**
   - 「同一引数を複数回指定したらエラー」「エラーの判定優先度」などを仕様化
   - req が例外型（`ValueError` 等）まで指定していない場合は、
     - `## 例外` の型を特定せず、`TBD（エラー種別は detail に未記載）` または `detail に従う` として明記する
