結論：**実ファイルは確認できなかったため、過去会話で確認できる既存テンプレート名を「論理ファイル単位」でマッピングします。** File Library では該当CIテンプレート実体は見つからず、写真ファイルのみ確認されました。

## 5分類マッピング

| ----------------------------------------------- | ---------: | ---------------------------------------------- |
| `.github/workflows/codeql.yml`                  |     共通層へ移す | `workflows/codeql.yml`                         |

## 最終配置案

```text
github-actions-ci-standard/
├── README.md
├── policy/
│   ├── ci-policy.md
│   ├── security-policy.md
│   ├── permissions-policy.md
│   ├── action-pinning-policy.md
│   └── artifact-policy.md
├── workflows/
│   ├── ci.yml
│   ├── security.yml
│   ├── codeql.yml
│   └── dependency-review.yml
├── adapters/
│   ├── ruby.yml
│   ├── python-uv.yml
│   ├── node.yml
│   ├── c.yml
│   ├── cpp.yml
│   └── php.yml
├── features/
│   ├── coverage.yml
│   ├── monorepo-path-filter.yml
│   ├── release.yml
│   └── sarif-upload.yml
└── targets/
    └── embedded/
        ├── host.yml
        ├── arm-none-eabi.yml
        └── arm-linux-gnueabihf.yml
```

## 優先して分類確定する順番

1. **共通層へ移すもの**
   `permissions`, `CodeQL`, `dependency-review`, `secret scan`, `artifact`, `pinning`

2. **adapterへ残すもの**
   Ruby / Python+uv / Node / C / C++ / PHP の言語固有処理

3. **featureへ分離するもの**
   coverage、release、SARIF、monorepo、embedded cross compile

この時点では、**削除対象は確定しません**。実ファイルを読めていないため、すべて「統合候補」または「要確認」です。
