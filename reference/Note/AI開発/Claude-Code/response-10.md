## Claude Code で新しい会話を始める方法

### 方法1: `/clear` コマンド（現在のセッション内でリセット）

```
/clear
```

会話履歴をクリアして、同じセッション内で新しい会話を始めます。

### 方法2: Claude Code を再起動

現在のセッションを終了して新しく起動：

```bash
# Ctrl+C または /exit で終了後
claude
```

### 方法3: 新しいターミナルで起動

別のターミナルウィンドウを開いて `claude` を実行すると、独立した新しいセッションが始まります。

---

**違い**:
| 方法     | 会話履歴 | ワーキングディレクトリ |
| -------- | -------- | ---------------------- |
| `/clear` | リセット | 維持                   |
| 再起動   | 新規     | 起動時のディレクトリ   |
