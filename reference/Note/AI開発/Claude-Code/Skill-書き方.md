 引数を取るskillにおいて、引数のデフォルト値を設定する方法を教えて

Claude Codeのスキル（SKILL.md）には、関数のような正式な引数スキーマや「デフォルト値」を設定する仕組みはありません。args は単なる自由形式の文字列としてスキルに渡され、その解釈はすべて SKILL.md の指示文（Markdown）に書かれたロジックに委ねられます。

したがって「デフォルト値を設定する」とは、args が省略された場合にどう振る舞うかを SKILL.md の中で明示的に指示しておくことを意味します。

やり方

「起動パラメータの抽出」節に、未指定時のフォールバックを一文加えるだけです。

| パラメータ | 例 | 説明 |
|-----------|-----|------|
| `target` | `gistx` | `docs/from_source/spec/external/<target>.md` の対象名（拡張子なし）。
  **省略時は `index` を対象とする** |

あるいは処理手順側に条件分岐として書く方法もあります。

### Step 0: target の決定

ユーザ指定があればそれを使う。`target` が指定されていない場合は既定値として `index` を使う。

いずれの書き方でも、実行時にモデルが「argsが空/target未指定 → 既定値を採用」という指示を読んで従う、という仕組みです（コード側でバリデーションされるわけではありません）。

---
具体的にどのスキルの target にどんなデフォルト値を設定したいか教えていただければ、該当の SKILL.md を直接編集します（例: external-spec-contradiction-check の target 省略時は index にする、など）。
