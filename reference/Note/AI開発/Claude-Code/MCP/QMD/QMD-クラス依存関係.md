出力ファイル

docs/diagrams/class_dependency.mmd

内容の要約

このコードベース（src/**/*.ts）は関数ベースの設計が中心で、store.ts・db.ts・cli/qmd.ts・mcp/server.ts・collections.ts・ast.ts・paths.ts はいずれも class を1つも定義していません。実際に class が存在するのは以下5つ、すべて llm.ts と maintenance.ts のみです。

┌──────────────────────┬────────────────┬──────────────────────────────────────────────────────────────────────────┐
│        クラス        │    ファイル    │                                   役割                                   │
├──────────────────────┼────────────────┼──────────────────────────────────────────────────────────────────────────┤
│ LlamaCpp             │ llm.ts         │ LLM                                                                      │
│                      │                │ インターフェースを実装。モデルのロード/embed/rerank/expandQueryを担当    │
├──────────────────────┼────────────────┼──────────────────────────────────────────────────────────────────────────┤
│ LLMSessionManager    │ llm.ts         │ LlamaCpp を保持し、セッションの参照カウント管理                          │
├──────────────────────┼────────────────┼──────────────────────────────────────────────────────────────────────────┤
│ LLMSession           │ llm.ts         │ ILLMSession を実装。LLMSessionManager                                    │
│                      │                │ に処理を委譲するスコープ付きセッション                                   │
├──────────────────────┼────────────────┼──────────────────────────────────────────────────────────────────────────┤
│ SessionReleasedError │ llm.ts         │ 組み込み Error を継承（外部クラスのため図には描画せず）                  │
├──────────────────────┼────────────────┼──────────────────────────────────────────────────────────────────────────┤
│ Maintenance          │ maintenance.ts │ Store（store.ts の型）を保持し、DBメンテナンス操作をラップ               │
└──────────────────────┴────────────────┴──────────────────────────────────────────────────────────────────────────┘

依存関係が意味を持つように、実装対象の3つの interface（LLM, ILLMSession, Store）も参考情報として図に含めています。

図の構造（依存関係）

LLM <|.. LlamaCpp              : 実装
ILLMSession <|.. LLMSession    : 実装
Maintenance ..> Store          : DB操作をラップ
LLMSessionManager ..> LlamaCpp : モデル取得・操作を委譲
LLMSession ..> LLMSessionManager : セッション管理を委譲
LLMSession ..> SessionReleasedError : 例外生成

補足（検証時のハマりどころ）

Mermaidレンダラーの検証中、<<interface>> ステレオタイプ注釈がコメント文中に書いただけでもパーサーがエラーを起こすという挙動を発見したため、代わりに %% コメントで (interface) と注記する形にしています。ファイル自体は %% コメントの説明ブロックで始まり、classDiagram 宣言、クラス定義、関係の順で構成されています。
