# フォルダ分類スキル

ユーザーのワークスペース直下に存在するフォルダを分類し、Markdown形式の表として出力する。

分類ロジックの正（source of truth）は同梱スクリプト `scripts/analyze_folders.py` である。ロジックの変更はスクリプト側で行い、このファイルには恒常的なコードを置かない。

## 分類観点（概要）

1. **空フォルダ** 
2. **フォルダのみ** 
3. **ファイルのみ** 
4. **ディレクトリ+ファイル** 

## 手順

1. 同梱スクリプトを対象ディレクトリに対して実行する。スクリプトがMarkdown表とサマリーまで出力する。

```bash
python3 /mnt/skills/user/folder-classify/scripts/analyze_folders.py <対象ディレクトリ>
```

2. 出力された表とサマリーをそのまま提示する（列構成・並び順・サマリー書式はスクリプトの出力に従う）。

3. スクリプトが見つからない・実行できない場合のみ、上記「分類観点」と同等のロジックをその場でPythonで実装する。恒常的な代替コードをこのファイルに追記しないこと。

## 注意事項

- `.git` 以外の隠しディレクトリ（`.github`, `.bundle` など）は「フォルダ」としてカウントするが、`.git` の存在判定には使用しない
- `git remote` コマンドはタイムアウト5秒で実行し、失敗した場合は `remote=なし` として扱う
