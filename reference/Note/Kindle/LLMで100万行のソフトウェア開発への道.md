# 引用
Where LLM Agents Fail, arXiv 2509.25370
(A Survey of LLM Alignment, arXiv 2502.09101)、
「LLM の信頼性はモデルを賢くする問題ではなく、 系の工学の問題だ」
「Lost in Conversation」 (Intent Mismatch Causes LLMs to Get Lost in Multi-Turn Conversation, arXiv 2602.07338)
モデルの能力不足ではなく意図整合のずれであると明示されています。 曖昧入力に確認を求めず既定解釈を選ぶ 「fuzzy interpretation」 (Survey of LLM Alignment, arXiv 2502.09101)、
長い指示の後方を落とす 「情報希釈」 (Unite.AI, Why Large Language Models Skip Instructions, 2025)

OpenAI 系の Reward Hacking (2016以降、 報酬信号を満たす短絡経路が学習される現象)、 DeepMind の Specification Gaming (2020、 仕様の字面は満たすが意図は満たさない挙動の60例以上のリスト)、 グッドハートの法則の ML 応用 (指標が目標化すると指標が良い指標でなくなる)、 Anthropic の Sycophancy 研究 (2023-2024、 評価者が喜ぶ出力に LLM が引き寄せられる)、 Faithful Chain-of-Thought 研究 (LLM の推論連鎖が実際の計算と一致しない現象)、 コード生成の品質研究で報告される Rubber-stamp レビュー現象 (機械が承認印を押すだけのレビュー)、 といったものが全て同じ根 (指定手順の無視とゴール形への短絡) を持っています。

誤り伝播 (error propagation) は長期タスクの主ボトルネックと位置づけられています (Where LLM Agents Fail, arXiv 2509.25370)。

CR 増幅に対応する機構も 「self-conditioning」 として分離 · 命名されています — 文脈にモデル自身の過去の誤りが入ると更に誤りを出しやすくなる (Illusion of Diminishing Returns, arXiv 2509.09677)。

METR の長期タスク計測では、 数分のタスクはほぼ確実に成功する一方、 数時間規模では成功率が一割未満へ落ちます (METR, arXiv:2503.14499)。
