# Writer
odt OpenDocumentFormat ZIP圧縮+XML構造　テキスト本体(content.xml),書式情報(styles.xml),埋め込み画像(Pictures/)など
ott OpenDocument Text Template
# Calc
ods OpenDocument Spreadsheet ZIP圧縮+XML構造
ots
# Impress
odp OpenDocument Presentaion ZIP圧縮+XML構造, 埋め込み画像(Pictures/)
otp
# Draw
odg OpenDocument Drawing オープンなベクターグラフィックス ZIP圧縮＋XML構造: 他のODF形式と同様にZIPアーカイブであり、ベクター座標やオブジェクト配置情報はすべて content.xml 内にタグ（SVGに類似した構造）で記述される。 Pictures/         # 外部から貼り付けたラスター画像（ビットマップ等）
otg
# Math
odf　OpenDocument Formula ZIP圧縮+MathML構造
sxm
# Base
odb　OpenDocument Database
