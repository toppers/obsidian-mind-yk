## 検証と調査

See [[Patterns - 検証と調査]].

- [[Patterns - 検証と調査 Archive#自前パーサと自前シリアライザのround-tripは、方言が外界の仕様から外れていても永久に緑になる（2026-09-13）|自前パーサ＋自前シリアライザのround-tripは方言のズレを検出できない]] — パーサとシリアライザが同じ方言を共有していれば常に一致する。検証の環が系の内側で閉じている典型。
- [[Patterns - 検証と調査 Archive#依存をモックした契約テストは、実際のランタイム統合を検証しない（2026-09-08）|モックした契約テストは実ランタイム統合を検証しない]] — 上と同じ構造の失敗。
- [[Patterns - 検証と調査 Archive#enforcement ruleは「違反を検知できること」自体を検証する（2026-09-06）|enforcement ruleは「違反を検知できること」自体を検証する]]
- [[Patterns - 検証と調査 Archive#実装前にリポジトリの実態を確認する（2026-09-06、2件目の発生）|実装前にリポジトリの実態を確認する]]
- [[Patterns - 検証と調査 Archive#単一実行ファイルのバンドル JS を文字列走査して挙動を確定する|バンドルJSを文字列走査して挙動を確定する]]
- [[Patterns - 検証と調査 Archive#shardmind をクロバーなしで更新する（2026-09-09）|shardmindをクロバーなしで更新する]]
- [[Patterns - 検証と調査#移植の正解は、移植元を実際に実行するオラクルで取る（2026-09-27）|移植の正解は移植元を実行するオラクルで取る]] — データは移植元の処理系にevalさせて抽出、挙動は差分テストで固定。正解データと同じ処理系の版でも走らせる。
- [[Patterns - 検証と調査 Archive#Ruby構造解析は正規表現の行走査でなくAST（`RubyVM::AbstractSyntaxTree`）を使う（2026-09-24）|Ruby構造解析は正規表現でなくASTを使う]] — 行走査はヒアドキュメント内の文字列を本物の定義と誤認しうる。
- [[Patterns - 検証と調査#正解データで検証できない範囲は移植しない——先に正解データを採る（2026-09-28）|検証できない範囲は移植しない]] — 範囲は「移植できるか」でなく「一致を確かめられるか」で決める。対象ケースがゼロなら先に正解データを採る。
- [[Patterns - 検証と調査#移植済みで呼び出し元のない API は、初めて使うときに疑う（2026-09-28）|呼び出し元のない移植済みAPIは初めて使うときに疑う]] — 差分テストの保証は実行された経路だけ。同じ役割の他経路と前提をそろえているか比べる。
- [[Patterns - 検証と調査#Ruby の include を Python の多重継承に写すときは、mixin を親クラスより前に書く（2026-09-28）|Ruby の include は Python の基底クラスで親クラスより前に書く]] — `include A; include B` は `class X(B, A, Base)`。移植したメソッドが効かないときは `__mro__` を Ruby の祖先順と比べる。
