## 1. 概要

### 1.1 目的

本文書は、[[TECSCDE外部仕様]] が定める外部仕様（JS版・フレームワーク非依存、全11章）を実装するための内部設計を記述する。対象は TECS WG メンバのうち、TECSCDE JS版の実装に着手する開発者（当面は自分自身）。

### 1.2 対象範囲 — 外部仕様との対応

| 外部仕様の章 | 内部仕様での対応 |
|---|---|
| 1. 概要、2. 動作環境 | 本章（1章）の前提として参照。独立した内部仕様の章は設けない |
| 3. 画面構成 | 6章（描画・インタラクション）、8章（ファイルI/O、UIシェル部分） |
| 4. コンポーネント図の表現 | 3章（モデル設計） |
| 5. ファイル操作 | 4章（CDLパーサ／シリアライザ）、8章（ファイルI/O） |
| 6. 編集操作 | 5章（編集コマンドとUndo/Redo） |
| 7. 表示機能 | 7章（表示制御） |
| 8. CDL 連携 | 4章、10章（tecsgen連携） |
| 9. エラーと警告 | 9章（整合性チェックとメッセージ） |
| 10. 制約・制限 | 各章に分散。2.3 の境界設計判断で横断的に参照 |
| 11. 用語集 | 参照のみ。内部仕様側に独立した用語集は設けない |

### 1.3 対象読者

TECSCDE JS版の実装に着手する開発者。外部仕様（何を作るか）は前提知識とし、本書は「どう作るか」に専念する。
