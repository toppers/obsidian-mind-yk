# TECSCDE-DT外部仕様 — 配列の呼び口の結合の添字（4.6.x）の追加案

**状態: 論点 A〜D を決定（2026-11-02）。外部仕様 第4章・第9章と内部仕様 4B へ反映済み。実装は実装リポジトリの PR #23（2026-11-02 マージ、マージコミット `1a5cc4e`）で完了。実機では、`tEV3Sample.tecsgen-opts` を開いて警告が 0 件（修正前 19 件）になり、結合の線分が描画されることを確認。保存と読み込み直しは単体テストのみ。** [[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 04 コンポーネント図の表現|DT外部仕様 第4章]]の 4.6「結合」の下に、小節 4.6.x「配列の呼び口への結合」を新設する案。

## 背景

- `tEV3Sample.tecsgen-opts` を開くと、`W-MISSING-JOIN-TARGET` が 19 件出る。すべて、プラグインが生成するセル `VM_TECSInitializer`（`nMruby::tTECSInitializer`）の `cInitialize[] = …;` の 19 行。実装リポジトリで原因を調べた（2026-11-02）。
- 原因は、**添字を省いた結合 `cPort[] = c.e;` を、アプリが扱えていない**こと。構文の読み取り（`cst.ts`）は添字なしの結合として読み、呼び口の要素の作成（`document-builder.ts`）は添字つきの結合だけを数える。このため可変長の呼び口が 1 要素（添字 0）だけになり、結合先の探索が「添字 `null`」の呼び口を探して、見つけられない。
- この書き方は正しい CDL。tecsgen 自身のサンプル（`tests/hr-tecs/tecsgen/samples/FigureSamples/carray/carray.cdl`）に、固定長 `cCall[2]` へ `cCall[] = Cell2.eEntry; cCall[] = Cell3.eEntry;` と書く例がある。
- 現行の外部仕様（DT 外部仕様、JS 版の外部仕様）には、添字の省略の規定がない。

## tecsgen での意味（ソースで確認済み）

出典は `tests/hr-tecs/tecsgen/tecsgen/tecslib/core/` の `bnf.y.rb`（`join` の構文規則）と `componentobj.rb`（`Join`、`add_array_member`）。

1. 構文規則 `cae_name '[' ']' '=' expression ';'` は、添字 `-1`（「添字を指定していない」）の結合になる。
2. 省略形の結合は、`add_array_member` が配列の**末尾へ追加**する。つまり、書かれた順に 0, 1, 2…。
3. 呼び口配列の**最初に現れた結合**が明示形か省略形かで、その呼び口の方式が決まる。後続が合わないと、エラー `S1128`（`inconsistent array definition`）か `S1130` になる。**明示形と省略形は混在できない。**
4. 明示形で同じ添字を再度指定すると、エラー `S1129`（`redefinition of subscript`）になる。

メッセージの正確な文言は、tecsgen を実行して確かめていない（ソースの読解のみ）。

## 提案する節の本文（4.6.x 配列の呼び口への結合）

1. 配列の呼び口（固定長 `[N]`、可変長 `[]`）への結合は、添字を書く `cPort[2] = c.e;` と、省く `cPort[] = c.e;` の 2 つの書き方を読み込む。
2. 添字を省いた結合は、同じセルの同じ呼び口の中で、**書かれた順に 0, 1, 2… の添字を割り当てる**。
3. 1 つの呼び口に、添字を書いた結合と省いた結合が混ざっているときは、不整合として診断する（tecsgen もエラーにする）。診断は警告にとどめ、読み込みは続ける。
4. 可変長の呼び口の要素数は、添字を書いた結合では「最大の添字＋1（最低 1）」、省いた結合では「結合の数」とする。固定長は `N`。
5. 図には、要素ごとに呼び口を表示し、割り当てた添字で結合を結ぶ。
6. 保存では、**変更していない呼び口の結合は、読み込んだ書き方のまま書き戻す**。結合を付け替えた、または削除した呼び口は、全要素を添字つきで書く。
7. `W-MISSING-JOIN-TARGET` の意味は変えない。結合先のセルまたは受け口が無いときだけ出す。

## 論点と推奨

| | 論点 | 推奨 |
|---|---|---|
| A | 添字を書いた結合と省いた結合が混ざったとき | **解決済み**: tecsgen に合わせ、不整合として診断する（本文 3） |
| B | その診断のコード | **決定: 新しいコードを足す**。例: `W-JOIN-INDEX-INCONSISTENT`（コードの名前は例で、第9章へ反映するときに確定する）。既存の `W-MISSING-JOIN-TARGET` には混ぜない（意味が違う） |
| C | 固定長 `[N]` で、N 個を超えて結合したとき、または同じ添字を再度書いたとき | **決定: 今回は規定しない。**tecsgen は `S1129` などでエラーにするが、実装を広げすぎないため |
| D | 保存の書き方 | **決定: 本文 6 のとおり**（変更した呼び口は全要素を添字つきで書く）。付け替え後に省略形のまま書くと、順序が変わったとき意味が変わるため、変更した呼び口は添字つきにする |
