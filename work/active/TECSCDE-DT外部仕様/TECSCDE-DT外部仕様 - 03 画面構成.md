## 3. 画面構成

### 3.1 メインウィンドウ

画面領域の構成（ツールバー・キャンバス・セルタイプ一覧・プロパティ・表示制御バー・ステータス表示）は[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 03 画面構成|TECSCDE外部仕様3.1節]]と同一とし、**変更しない**。単一ウィンドウ内にすべての領域を配置する構成は、[[TECSCDE外部仕様]]がブラウザのタブという制約から導いたものだが、デスクトップアプリとして複数ウィンドウ（例: パレットを独立ウィンドウにする現行版 Ruby/GTK 版のような構成）を採用する積極的な理由もないため、単一ウィンドウ構成をそのまま踏襲する。

デスクトップアプリとして新たに規定する点は次の2つである。

- **ネイティブメニューバーを追加してよい。** Electron（`Menu`モジュール）・Tauri（メニューAPI）はいずれもOSネイティブのメニューバーを提供できる。ツールバー（3.1.2既定）に加えて、File／Edit／View等のメニュー項目からも同じ操作（保存・元に戻す等）を実行できるようにしてよい。ツールバーの機能を置き換えるものではなく、追加の入口として位置付ける。なお「開く」はファイルブラウザ（3.5.1節、2026-09-21）に一本化しており、メニューに複製の入口を設けない。
- **終了操作を追加する。** [[TECSCDE外部仕様]]3.3.2は「終了ボタンは設けない。ブラウザのタブ／ウィンドウを閉じる操作が終了操作に相当する」と規定していたが、デスクトップアプリではウィンドウを閉じる操作（OSの閉じるボタン、またはメニューのFile > Exit）が実際のプロセス終了に対応する。未保存の変更がある場合の確認は、[[TECSCDE外部仕様]]5.7.2の「未保存の変更がある状態でページを離れようとした場合、確認を求める」という方針をそのまま踏襲し、実現手段をブラウザの`beforeunload`から、ウィンドウを閉じる直前のイベント（Electron: ウィンドウの`close`イベント、Tauri: `onCloseRequested`）に置き換え、そこでOSネイティブの確認ダイアログ（「保存せずに終了」「キャンセル」の2択）を出す。ブラウザの`beforeunload`には依存しない（2026-10-22改訂。`beforeunload`で終了を止める方式は、実機で確認なしに終了してしまった。詳細は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 05 ファイル操作|第5章5.7節]]）。

### 3.1.x 画面構成の変更（V0.2.0 で変更、2026-11-05）

V0.2.0 で、表示制御バー（[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 03 画面構成|TECSCDE外部仕様3.1.2]]）を**なくす**。経緯は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 追加案(V0.2.0用)|追加案(V0.2.0用)]]。

1. **表示制御バーをなくす。** 領域ごとの表示／非表示を切り替える操作そのものを廃止する。
2. **常時表示する領域**: ツールバー、プロパティパネル、ステータス表示。
3. **ダイアログにする領域**: セルタイプ一覧、ファイルブラウザ（3.5.1）。
   - セルタイプ一覧のダイアログは、セルタイプの選択（[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 03 画面構成|TECSCDE外部仕様3.3]]のパレットの役割）をダイアログで行う。
   - 2つのダイアログを開くツールバーのボタンを置く。ファイルブラウザは「**ファイル**」ボタン（3.5.1）、セルタイプ一覧は「**セルタイプ一覧**」ボタン。
   - 2つのダイアログは**モードレス**（開いたまま、キャンバスの操作を続けられる）。セルタイプの選択とキャンバスへの配置を続けて行えるようにするため（2026-11-05 決定）。
4. **「リージョン」ボタンを加える。** 押すたびに、リージョンの**追加の表示モード**（4.9.x）の有効・無効を切り替える。既存のリージョンの色分け表示と凡例（リージョンバー、4.9）は変更せず、そのまま残す。

### 3.2〜3.7

キャンバス（座標系・描画方式・スクロール）、パレット（セルタイプ一覧・選択モード）、プロパティパネル、ナビゲータ、ダイアログ、モードとカーソルの規定は、[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 03 画面構成|TECSCDE外部仕様3.2〜3.7節]]と**同一、変更なし**。いずれもブラウザ・デスクトップの実行形態に依存しない画面設計上の規定である。

主な例外は3.5節（ファイルブラウザ）である（このほか、デスクトップ版で3.4.x節・3.8節を追加した）。[[TECSCDE外部仕様]]3.5節は「ファイルブラウザは提供しない」と規定し、理由を2つ挙げていた——(a) 現行版（Ruby/GTK版）も持たない、(b) ブラウザはローカルのディレクトリツリーを列挙できない。デスクトップ版では(b)が成り立たなくなる（第2章2.3節、第10章10.1節）。(a)は変わらず成り立つが、tecsgen由来のCDLファイル群は`import`/`import_C`（第8章8.1節）でディレクトリ階層にまたがって参照し合うことが多く、5.3節のファイル選択ダイアログだけでは対象ファイルの見通しが悪いという実用上の理由から、**2026-09-21、本仕様ではファイルブラウザを採用する**（旧稿の見送りを撤回。第10章10.4節の記載も改める）。

#### 3.5.1 ファイルブラウザの規定

- **ダイアログとして提供する（V0.2.0 で、サイドパネルから変更、2026-11-05。3.1.x）。** 表示制御バーの廃止により、表示／非表示の切り替え（3.1.2）はなくなり、ダイアログを開く・閉じる操作に置き換わる。
- 起点はツールバーの「**ファイル**」ボタンとする（V0.2.0 で「フォルダを開く」ボタンから名称変更、2026-11-05。押すとファイルブラウザのダイアログを開く。ルートフォルダの指定は、現行の「フォルダを開く」の機能をダイアログ内に移す形とする）。OSネイティブのディレクトリ選択ダイアログでルートフォルダを指定する。
- ルートフォルダ配下を**階層ツリー**として表示する。ディレクトリは展開・折りたたみができる。
- `.cde`・`.cdl`・`.tecsgen-opts`のファイルのみを列挙対象とする（`.tecsgen-opts`は大文字小文字を区別し、大文字を含む拡張子は列挙しない。`.tecsgen-opts`は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 05A 開く（読み込み）|第5章5.3節]]のtecsgenオプション形式ファイル。2026-10-21、拡張子の定義を統一）。tecsgenプロジェクトのディレクトリには本アプリに関係のないファイルが多数含まれるため、それ以外の拡張子は表示しない。
- ツリー上のファイルをクリックすると、そのファイルを編集対象として開く。`.tecsgen-opts`をクリックしたときは、そのファイルに列挙されたCDLファイル群をまとめて読み込む（最後を主ファイルとする。[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 05A 開く（読み込み）|第5章5.3節]]）。ツールバー操作から編集対象を選ぶ**唯一**の経路とする——当初はOSネイティブのファイル選択ダイアログも並行提供する想定だったが、実機確認により2つの「開く」入口が利用者を混乱させると判明したため撤回した（2026-09-21、第5章5.3節参照）。未保存の変更がある場合は5.7節の確認を経る。
- **Ctrl+クリックで、現在の主ファイルを置き換えずにCDLファイルを追加で読み込める。** 通常のクリックは主ファイルを切り替えるが、Ctrl+クリックは現在のファイル集合と未保存の変更を保持する。既に読み込み済みのファイルは重複追加しない。追加したCDLがユーザ定義CDLであれば、そのセルも編集可能とし、変更はその定義元ファイルへ保存する（システム定義CDLのセルは既定で編集不可、第5章5.3節。第5章5.4節、第8章8.1節）。
- 現在の主ファイルと、Ctrl+クリックまたは`import`で追加読み込みしたファイルを、ツリー上で異なる様式で強調表示する。この区別はファイルの開き方とセッション上の役割を表し、セルの編集可否は表さない。色・アイコン等の具体的な様式は実装時に定める。
- ツリーの展開状態・選択位置はアプリケーション実行中の状態としてのみ保持し、CDEファイルの保存内容には含めない（5.5節「レイアウト情報の復元」とは無関係）。
- **ルートフォルダは終了後も記憶し、次回起動時に自動的に復元する（2026-09-21追加）。** 上記のツリー展開状態・選択位置とは異なり、ルートフォルダの選択自体はセッションをまたいで維持する利用者設定として扱う——`.cde`ファイル1つずつではなく、tecsgenプロジェクトのディレクトリ単位で継続して作業することが多いため。CDEファイルの保存内容（5.1節）には含めず、アプリケーション単位の設定として別途保持する。記憶したフォルダが次回起動時に存在しない・アクセスできない場合はエラーとせず、フォルダ未選択の状態で起動する（フォルダ選択そのものを利用者操作に委ねる、5.3節と同じ「解決できない場合は黙って進める」方針）。

### 3.4.x プロパティパネルの定義ファイル（デスクトップ版で追加、2026-11-02）

3.4.2の規定に加えて、プロパティパネルの**一番下**に、選択したセルを定義している CDL ファイルのフルパスを「定義ファイル」として表示する。複数のファイルを同時に読み込むため、選択したセルがどのファイルのものかを、保存先と合わせて確かめられるようにする。

1. 表示するのは、セルを**1つだけ**選択したときのみ。参照専用のファイルから読み込んだセルは、そのファイルのパスを表示する（編集対象のファイルのパスではない）。
2. パスは OS の表記のまま、長いものは折り返し、選択してコピーできる。
3. ファイルを持たないセル（Plugin が生成したセル、保存前の新規作成のドキュメントのセル）は、パスの代わりに「パスなし」と表示する。
4. 複数のセルを選択したときは表示しない（セルごとに定義元が異なりうるため）。
5. セルタイプの詳細ダイアログにも、同じ趣旨で、そのセルタイプを定義しているファイルのフルパスを出す（[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 04 コンポーネント図の表現|第4章4.2.x]]）。
6. **プロパティパネルにスクロールバーを付ける**（V0.2.0、2026-11-05）。表示内容が領域に収まらないときに、縦のスクロールバーを出す（横方向は TBC）。
7. **セルの定義ファイルの表示ボタン**（V0.2.0）。「定義ファイル」のパスの横にボタンを置く。押すと「**セル定義ファイルウィンドウ**」を開き、そのファイルの内容を表示する。表示だけで、編集はしない。パスが「パスなし」のときは、ボタンを使えなくする。複数のセルを選択したときは、パスと同様に表示しない。
8. セルタイプの詳細ダイアログ（4.2.x）にも、同じ趣旨でボタンを置く（4.2.x）。

### 3.8 バージョン情報（デスクトップ版で追加、2026-11-01）

3.6のダイアログに加えて、アプリケーション自身の版を確認するダイアログを設ける。経緯は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 バージョン表示追加案|追加案]]。

1. ツールバーに「**情報**」ボタンを置く。押すと、バージョン情報のダイアログ（モーダル）を開く。
2. ダイアログに次を表示する。

   | 項目 | 内容 |
   |---|---|
   | アプリケーションの版 | 2.5.5 の版（例: `0.1.0`） |
   | ビルド | コミットの短縮ハッシュ。ビルド時に取得できなかったときは `unknown` |
   | 形式の版 | `cde_format_version`（例: `0.1.0.0`） |
   | tecsgen | 起動時の確認（第8章8.4.2節）で読み取れた版と、使われている起動コマンド。確認できていないとき（見つからなかったときを含む）は「未確認」 |
   | 実行環境 | Electron・Chromium・Node の版、OS の種類 |

3. 「**コピー**」ボタンで、上の内容を、1項目1行（`項目名: 値`）のテキストとしてクリップボードに入れる。不具合の報告に貼る用で、書式は貼り先を選ばない。
4. 閉じるボタン、Esc で閉じる。

#### 3.8.1 設定の欄（V0.2.0 で追加、2026-11-05）

V0.2.0 で、設定ダイアログを採用する（2.5.1 の「設定画面を設けない」を改める）。**設定ダイアログは、このバージョン情報のダイアログと同居させる**——「情報」ボタンで開く1つのダイアログに、バージョン情報（上）と設定の欄を置く。tecsgen のパスの設定画面の追加案（[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 tecsgenパス設定画面追加案|追加案]]）の「設定」ボタンを別に置く案は、この決定で置き換える。

1. **tecsgen へのパス**: 現在の値を表示し、設定できる。`settings.json` には、tecsgen へのパス（`tecsgenPath`）を保存する。パスは、次の順に決める。
   1. `settings.json` の `tecsgenPath`（設定済みのとき）。
   2. 未設定のとき、環境変数 `TECSPATH` の値を調べ、その値が**実際に存在する**なら、それを tecsgen へのパスとする。
   3. 2 で決まらないとき、環境変数 `PATH` で指定されたディレクトリを**先頭から順に**探す。実行している OS に応じて、実行ファイルのファイル拡張子を選んで探す（Windows の拡張子の一覧は TBC）。
   4. 見つかったパスは、tecsgen へのパスとして使い、設定として保存する。見つからないときは未設定のままにして、その旨を表示する。
   - 入力欄、「参照…」、「確認」（`--version` の実行結果の表示）を置く。保存は、確認の成否に関わらず行える。空にして保存すると解除する（次回は上の順で決め直す）。
   - 環境変数 `TECSGEN_COMMAND` が設定されているときは、従来どおりそちらが優先され、この設定が使われないことを表示する。
2. **環境変数 `TECSPATH`**: ダイアログには**値を表示するだけ**とする（ダイアログからは設定できない）。
3. **環境変数 `PATH`**: ダイアログには**表示しない**。tecsgen の探索（1 の 3）にだけ使う。
4. 保存した直後から、その値を使う（再起動は不要）。tecsgen の版の確認（第8章8.4.2）も、保存のときにもう一度行う。

設定の項目と置き場所は2.5、動作は8.4.3、エラーの案内は9.4。

#### 3.8.2 CDLファイル一覧の作成（V0.2.0 で追加、2026-11-05）

ダイアログに、`_ROOT_CDL_FILES.txt` を作る欄とボタンを置く（規定は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 05A 開く（読み込み）|5.3.y]]）。

1. 「**対象のディレクトリ**」: 表示と設定ができる。ディレクトリ選択ダイアログで指定する。
2. 「**CDLファイル一覧を作成**」ボタン: 押すと、5.3.y の処理を行う。
3. 作成した `_ROOT_CDL_FILES.txt` のフルパスと、作成した `_CDL_FILES.txt` の件数を、ダイアログに表示する。
