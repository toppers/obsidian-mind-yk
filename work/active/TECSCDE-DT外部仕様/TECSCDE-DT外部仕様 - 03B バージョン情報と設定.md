### 3.8 バージョン情報（デスクトップ版で追加、2026-11-01；V0.3.0 段1 改訂・実機確認済み 2026-11-20）

3.6のダイアログに加えて、アプリケーション自身の版を確認するダイアログを設ける。経緯は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 バージョン表示追加案|追加案]]。

1. ツールバーに「**情報**」ボタンを置く。押すと、バージョン情報のダイアログ（モーダル）を開く。
2. ダイアログに次を表示する（V0.3.0 で `実行コマンド:` を `tecsgenのコマンドラインオプション:` へ改称）。

   | 項目 | 内容 |
   |---|---|
   | アプリケーションの版 | 2.5.5 の版（例: `0.3.0`） |
   | ビルド | コミットの短縮ハッシュ。ビルド時に取得できなかったときは `unknown` |
   | 形式の版 | `cde_format_version`（例: `0.1.0.0`） |
   | `tecsgen:` | 起動時の確認（第8章8.4.2節）で読み取れた tecsgen のバージョン。確認できていないとき（見つからなかったときを含む）は「未確認」 |
   | `tecsgenのコマンドラインオプション:` | 実際に使われている tecsgen の起動コマンド列（従来の「実行コマンド:」から改称） |
   | 実行環境 | Electron・Chromium・Node の版、OS の種類 |

3. 「**コピー**」ボタンで、上の内容を、1項目1行（`項目名: 値`）のテキストとしてクリップボードに入れる。不具合の報告に貼る用で、書式は貼り先を選ばない。
4. 閉じるボタン、Esc で閉じる。

#### 3.8.1 設定の欄（V0.2.0 で追加、2026-11-05；V0.3.0 段1 改訂・実機確認済み 2026-11-20）

V0.2.0 で、設定ダイアログを採用する（2.5.1 の「設定画面を設けない」を改める）。**設定ダイアログは、このバージョン情報のダイアログと同居させる**——「情報」ボタンで開く1つのダイアログに、バージョン情報（上）と設定の欄を置く。tecsgen のパスの設定画面の追加案（[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 tecsgenパス設定画面追加案|追加案]]）の「設定」ボタンを別に置く案は、この決定で置き換える。

1. **tecsgen へのパス**: 現在の値を表示し、設定できる。`settings.json` には、tecsgen へのパス（`tecsgenPath`）を保存する。パスは、次の順に決める。
   1. `settings.json` の `tecsgenPath`（設定済みのとき）。
   2. 未設定のとき、環境変数 `TECSPATH` の値を調べ、その値が**実行できるファイルとして実際に存在する**なら、それを tecsgen へのパスとする（ディレクトリのときは採用せず、保存もせず、次の `PATH` 探索へ進む。2026-11-17 決定、三者相違一覧 1-5）。
   3. 2 で決まらないとき、環境変数 `PATH` で指定されたディレクトリを**先頭から順に**探す。実行している OS に応じて、実行ファイルのファイル拡張子を選んで探す（Windows では `tecsgen.bat`、`tecsgen.ps1` の順に探し、`tecsgen.exe` は探さない。2.4 節）。
   4. 見つかったパスは、tecsgen へのパスとして使い、設定として保存する。見つからないときは未設定のままにして、その旨を表示する。
   - 入力欄、「参照…」、「確認」（`--version` の実行結果の表示）を置く。保存は、確認の成否に関わらず行える。空にして保存すると解除する（次回は上の順で決め直す）。
   - 環境変数 `TECSGEN_COMMAND` が設定されているときは、従来どおりそちらが優先され、この設定が使われないことを表示する。
2. **環境変数TECSPATH:**: ダイアログには**値を表示するだけ**とする（読み取り専用入力欄で次の行に値を表示、ダイアログからは設定できない。V0.3.0 でラベルを `TECSPATH:` から `環境変数TECSPATH:` へ変更）。
3. **環境変数TECSGEN_COMMAND:**（V0.3.0 追加、2026-11-20 実装・実機確認済み）: `環境変数TECSPATH:` と同様に、読み取り専用入力欄で次の行に環境変数 `TECSGEN_COMMAND` の値を表示する（ダイアログからは設定できない）。
4. **環境変数 `PATH`**: ダイアログには**表示しない**。tecsgen の探索（1 の 3）にだけ使う。
5. 保存した直後から、その値を使う（再起動は不要）。tecsgen の版の確認（第8章8.4.2）も、保存のときにもう一度行う。
6. **Plugin 生成型の取り込み方式**（2026-11-08 追加）: 「外部 tecsgen（既定）」と「内部処理」から選べる。保存した後の、次の読み込みから使う。開いている CDL を、設定の変更で勝手に読み直さない。内部処理の対象は第8章8.5の付表に載ったプラグインだけで、対象外のプラグインは取り込まれない（警告 `W-PLUGIN-UNSUPPORTED`）。「実行(Generate)」と版の確認は、この選択に関わらず外部の tecsgen を使う。

設定の項目と置き場所は2.5、動作は8.4.3、エラーの案内は9.4。

#### 3.8.2 CDLファイル一覧の作成（V0.2.0 で追加、2026-11-05）

ダイアログに、`_ROOT_CDL_FILES.txt` を作る欄とボタンを置く（規定は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 - 05B CDLファイル一覧の作成と自動配置|5.3.y]]）。

1. 「**対象のディレクトリ**」: 表示と設定ができる。ディレクトリ選択ダイアログで指定する。
2. 「**CDLファイル一覧を作成**」ボタン: 押すと、5.3.y の処理を行う。
3. 作成した `_ROOT_CDL_FILES.txt` のフルパスと、作成した `_CDL_FILES.txt` の件数を、ダイアログに表示する。
