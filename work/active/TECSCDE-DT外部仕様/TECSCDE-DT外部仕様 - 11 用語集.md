## 11. 用語集

TCD・TECSCDE・CDL・CDE・セル・セルタイプ・呼び口・受け口・シグニチャ・結合・結合バー・複合セルタイプ・リージョン・ネームスペース・属性・配列ポート・グリッド・`__tool_info__`・整合性チェックの用語は、[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 11 用語集|TECSCDE外部仕様第11章]]の定義を踏襲する。`locale`・編集可否・参照ファイル・`direct_import`は本書の下記定義で上書きする。CDL言語一般の用語は[[tecsgen外部仕様]]の用語集を正とする。

本書固有の追加用語は次のとおり。

| 用語 | 定義 |
|------|------|
| Electron | TypeScriptによるデスクトップアプリ実装の想定フレームワークの1つ。Chromium＋Node.jsで構成（第1章1.3） |
| Tauri | Rustによるデスクトップアプリ実装の想定フレームワークの1つ。OSネイティブWebView＋Rustで構成（第1章1.3） |
| サブプロセス実行 | 本アプリケーションが外部プロセス（tecsgen本体・Cプリプロセッサ）をOSのプロセスとして起動し、標準出力・標準エラー出力・終了コードを取得する機構。Electron・Tauri両方で実現可能なため採用（第2章2.3、第8章8.4） |
| OSクリップボード連携 | コピーした要素をCDL断片としてOSネイティブのクリップボードへ書き込み、アプリ間・ウィンドウ間で貼り付けを可能にする機能。[[TECSCDE外部仕様]]では範囲外だったが、両フレームワークで実現可能なため本書で新規採用（第6章6.7） |

| `locale` | セルの定義元ファイルと行を指す情報。通常CDLでは保存先の特定に使い、主ファイルか追加読み込みファイルかによる編集可否の判定には使わない（第10章10.2節）。 |
| 編集可能／編集不可 | 読み込んだ通常CDL由来のセルは編集可能。Plugin生成CDL由来のセルは読み取り専用で、変更・削除・保存の対象外（第8章8.1節）。 |
| 主ファイル | 通常クリックまたは複数ファイル指定の最後から選ばれる、現在の作業の中心となるCDL。追加読み込みしたCDLと編集権限は同じ。 |
| 追加読み込みファイル | 手動追加、インポート追跡、複数指定などで主ファイルと一緒に読み込んだ通常CDL。セルは編集可能で、変更はこのファイルの元パスへ保存する。旧来の「参照専用ファイル」という呼称は編集権限を表さないため本書では使わない。 |
| `direct_import` | `__tool_info__("tecsgen")`に記録する直接指定ファイルの一覧。ファイル間の参照を示し、編集不可を意味しない（第8章8.2節）。 |
| Plugin生成CDL | tecsgenのPluginが一時生成するCDL。型・セルを図へ読み込むが、生成セルは読み取り専用とし、利用者のCDLやセッション参照先へ保存しない。 |
