## 4. コンポーネント図の表現

図を構成する要素そのもの（セル・セルタイプ・呼び口・受け口・シグニチャ・結合・複合セルタイプ・ネームスペース・リージョン）の表現は、実行環境（ブラウザかデスクトップか）に依存しない**CDL・TCDのモデル設計そのもの**であるため、[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 04 コンポーネント図の表現|TECSCDE外部仕様第4章]]と**4.1.x節・4.1.y節・4.2.x節・4.3.x節・4.6.x節・4.7節を除き同一**。アクティブなセルの背景色と色の重ね方は本章4.1.x節、状態表示（未結合は記号のみ）の整理は本章4.1.y節で定める。セルタイプの詳細ダイアログの定義ファイルは本章4.2.x節、`require`呼び口の表示は本章4.3.x節、配列の呼び口への結合の添字は本章4.6.x節、複合セルタイプは本章4.7節で定める。

- 4.1 セル（矩形表示、既定サイズ25×15mm、編集可否・不完全の色分け、未結合は記号のみ。4.1.x アクティブなセルの背景色と色の重ね方、4.1.y 状態表示の整理）
- 4.2 セルタイプ（図の独立要素とせず、セルの属性として扱う。4.2.x 詳細ダイアログの定義ファイル）
- 4.3 呼び口（辺上配置、結合最大1本、所属辺変更は明示操作。4.3.x 名前付き`require`は通常表示、名前なしは非表示）
- 4.4 受け口（呼び口と幾何は共通、結合は複数可）
- 4.5 シグニチャ（結合のラベルとして表示）
- 4.6 結合（水平・垂直の折れ線、シグニチャ一致で結合可否判定。4.6.x 配列の呼び口への結合の添字）
- 4.7 複合セルタイプ（外側を通常セルとして表示し、内部は展開しない）
- 4.8 ネームスペース（リージョンの識別子として統合）
- 4.9 リージョン（木構造、色分け表示＋凡例。4.9.x 矩形領域の重なりによる表現を V0.2.0 で追加）

4.1.x節・4.1.y節・4.2.x節・4.3.x節・4.6.x節・4.7節以外の詳細は[[TECSCDE外部仕様]]該当節を参照。

### 4.2.x セルタイプの詳細ダイアログの定義ファイル（2026-11-02 追加）

セルタイプ一覧の詳細表示操作で開くダイアログ（[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 03 画面構成|TECSCDE外部仕様 3.6.2]]の「セルタイプのプロパティ」）は、読み取り専用である。デスクトップ版では、その**一番下**に、そのセルタイプを定義している CDL ファイルのフルパスを「定義ファイル」として表示する。

1. 表示するのは、読み込んだ CDL のうち、そのセルタイプを定義しているファイルのフルパス（OS の表記のまま）。長いパスは折り返し、選択してコピーできる。
2. ファイルを持たないセルタイプ（外部の tecsgen で生成した Plugin 生成型、保存前の新規作成のドキュメントの型）は、パスの代わりに「パスなし」と表示する。内部処理（第8章8.5）で生成した型は、仮想のパス `plugin:<プラグイン名>/<ファイル名>` を表示する（項目5）。
3. 既存の「定義元」欄（ファイル名のみ）は、そのまま残す。
4. **定義ファイルの表示ボタン**（V0.2.0、2026-11-05）。パスの横にボタンを置く。押すと「**セルタイプ定義ファイルウィンドウ**」を開き、そのファイルの内容を表示する。表示だけで、編集はしない。パスが「パスなし」のときは、ボタンを使えなくする。
5. **内部処理で生成した型の定義ファイル**（2026-11-08）。仮想のパス `plugin:<プラグイン名>/<ファイル名>` を表示し、ボタンを使えるようにする。ウィンドウには、メモリ上の仮想ファイルの内容を**読み取り専用**で表示する。実在するパスではないため、パスのコピーと保存は行えない。

### 4.3.x `require`呼び口の表示（2026-11-07 改訂、監査#3）

[[TECSCDE外部仕様 - 04 コンポーネント図の表現]]4.3.2の「`require`指定の呼び口を図に表示しない」は、デスクトップ版では次の規定に置き換える。[[TECSCDE-DT-EL内部仕様 - 04B CDLパーサ設計]]の名前付き／名前なしの区別に合わせた決定である。

1. **名前付き**（`require 名前 = 要求先.受け口;`）は、利用者が結合できる**通常の呼び口として表示する**。通常の呼び口と同じ配置・結合操作の規則を適用する。シグニチャは要求先の受け口から解決する。
2. **名前なし**（`require 要求先.受け口;`）は、**図に表示しない**。そのセルの呼び口が省略されていることと省略数を、警告`W-REQUIRE-PORT-HIDDEN`で知らせる（第9章9.2）。
3. 名前付きの`require`は非表示・省略数・`W-REQUIRE-PORT-HIDDEN`の対象にしない。シグニチャが解決できない場合は、非表示扱いに変えず、`W-PORT-SIGNATURE-UNRESOLVED`で知らせる。

### 4.6.x 配列の呼び口への結合（2026-11-02 追加）

経緯と論点は[[work/active/TECSCDE-DT外部仕様/TECSCDE-DT外部仕様 配列呼び口の結合の添字追加案|追加案]]。tecsgen のソース（`bnf.y.rb`・`componentobj.rb`）で意味を確認した。

1. 配列の呼び口（固定長 `[N]`、可変長 `[]`）への結合は、添字を書く `cPort[2] = c.e;` と、省く `cPort[] = c.e;` の 2 つの書き方を読み込む。
2. 添字を省いた結合は、同じセルの同じ呼び口の中で、**書かれた順に 0, 1, 2… の添字を割り当てる**。
3. 1 つの呼び口に、添字を書いた結合と省いた結合が混ざっているときは、不整合として警告 `W-JOIN-INDEX-INCONSISTENT`（9.2）を出し、読み込みは続ける（tecsgen はこれをエラーにする）。
4. 可変長の呼び口の要素数は、添字を書いた結合では「最大の添字＋1（最低 1）」、省いた結合では「結合の数」とする。固定長は `N`。ただし、保存された可変長配列の個数情報がある場合は、結合から必要な要素数・保存個数・1の最大値を採用する（5.1.x）。個数情報がない旧ファイルでは従来の導出規則を維持する。
5. 図には、要素ごとに呼び口を表示し、割り当てた添字で結合を結ぶ。
6. 保存では、**変更していない呼び口の結合は、読み込んだ書き方のまま書き戻す**。結合を付け替えた、または削除した呼び口は、全要素を添字つきで書く。
7. 固定長 `[N]` の範囲外の添字、同じ添字の再指定は、本節では規定しない。

### 4.7 複合セルタイプ

CDL に定義された複合セルタイプのインスタンスは、外側のセルを通常セルと同じ矩形・セル名・セルタイプ名・外部ポートで図上に表示する。外部ポートを使った結合は通常セルと同様に表示する。

複合セルタイプの内部セル、内部結合、ポート転送を図上で展開しない。複合セルタイプの**定義**を図上で新規作成・編集する操作は提供しない。外側のセルに対する通常の操作は、セルの編集可否に従う。

読み込んだ複合セルタイプに本アプリが扱えない構文が含まれる場合、選択した外側のセルのプロパティ欄には**未対応構文が存在することのみ**を表示する。未対応構文の内容や内部構造は同欄に表示せず、編集させない。保存時には、読み込んだ複合セルタイプの定義を失わずに保持する。

### 4.1.x アクティブなセルの背景色（V0.2.0 で追加、2026-11-05）

`active` のセルタイプに属するセル（アクティブなセル）は、セルの**背景色を青色**にして、ほかのセルと区別する。

#### 色の重ね方（2026-11-08 決定）

セルの色は、**塗りと枠を別の軸**として決める。軸ごとに独立して決め、1つの状態が他の状態の表現を消さない。

| 軸 | 優先順位（高 → 低） |
|---|---|
| 塗り | アクティブ（青） > 編集不可（灰） > 通常（白） |
| 枠の色と線種 | 不完全（橙の破線） > 編集不可（淡灰の実線） > 通常（濃灰の実線） |

1. **アクティブかつ編集不可**: 青塗りに淡灰の実線枠となる。編集不可は枠と記号`RO`で示す。
2. **アクティブかつ不完全**: 青塗りに橙の破線枠となる。
3. **アクティブ・編集不可・不完全が同時**: 青塗り、橙の破線枠となる。記号`RO`と`!`は4.1.2のとおり併記する。
4. **未結合**: 塗りも枠も変えない。記号`U`だけで示す。
5. 選択枠、検索一致の破線枠、リージョンの色の帯、状態記号（`RO`・`!`・`U`）は、別の表示機構として塗り・枠の上に重ねる。これらの有無で、塗りと枠の色は変わらない。
6. 青は、セル名とセルタイプ名の文字（濃色）が読み取れる明度とする。文字と背景のコントラスト比は4.5:1以上を保つ。青の具体的な値は実装時に決める。
7. アクティブの有無は青の背景だけで示し、色以外の補助記号は設けない。4.1.2の「色以外でも識別」の要件は、編集不可・不完全・未結合を対象とするため、アクティブには適用しない。色覚への配慮が必要になった場合は将来検討する（TBC）。
8. 4.1の「未結合の色分け」は、デスクトップ版では色による区別を行わず、記号`U`のみで示す（整理は4.1.y）。

- アクティブなセルだけを表示する操作は7.5.x、最上段へ移動する操作は7.3.y。

### 4.1.y セルの状態表示の整理（デスクトップ版、2026-11-08）

[[work/active/TECSCDE外部仕様/TECSCDE外部仕様 - 04 コンポーネント図の表現|親仕様4.1.1・4.1.2]]の状態の色分けを、デスクトップ版では次のとおり読み替える。親仕様の記述自体は変更しない。

1. **色の値は継承しない。** 親仕様4.1.1の表（現行版の6色。青＝編集不可、マゼンタ＝強調表示中／未結合、赤＝不完全など）は現行版の表現であり、デスクトップ版には適用しない。デスクトップ版の色は4.1.xで定める。親仕様4.1.2の「色の値は実装に委ねる」趣旨は変えない。
2. **状態ごとの表示**は次のとおりとする。記号は[[TECSCDE-DT-EL内部仕様 - 05B 色に依存しない状態表示|内部仕様5B]]が具体化する。

   | 状態 | 色による表示 | 記号 |
   |---|---|---|
   | 編集不可 | 灰の塗り、淡灰の枠（4.1.x） | 四角囲みの`RO` |
   | 不完全 | 橙の破線の枠（4.1.x） | 三角囲みの`!` |
   | 未結合 | **なし**（塗りも枠も変えない） | 丸囲みの`U` |

3. **未結合は記号のみ**で示す。親仕様4.1.1の「マゼンタ＝未結合」と、4.1.2の「未結合は色に加えて形状または記号でも示す」のうち、未結合の色による区別は行わない。「色覚特性によらず判別できる」要件は、記号`U`で満たす。
4. 親仕様4.1.1の**マゼンタの「強調表示中」**は、この項の対象外とする。結合の強調は7.6、検索一致の強調は7.4のとおり別の機構で示す。
5. 状態を複数同時に持つセルは、該当する記号をすべて併記する（順序は`RO`、`!`、`U`）。色の優先順位によって1つに絞らない。

### 4.9.x リージョンの矩形領域による表現（V0.2.0 で追加、2026-11-05）

ツールバーの「リージョン」ボタン（3.1.x）で切り替える、リージョンの**追加の表示モード**。4.9 の色分け表示と凡例は変更しない。

1. リージョンを、**そのリージョンに含まれるセルを含む矩形領域の重なり**で表す。矩形領域は**分割しない**（セルを囲む矩形をそのまま重ねる）。
2. リージョンに割り当てた色で、**リージョンの外部と接する辺**だけを描く。リージョンの内部で矩形領域どうしが接する辺は、描かない。
3. **親子の重なり**（2026-11-08 決定）。親リージョンの矩形領域は、**自身と子孫のすべてのリージョンに属するセル**を含む。
   1. 子の領域は、親の領域の内側に入る。親は子より外側に描き、親と子の線は**間隔をあけて**重ならないようにする。間隔は、子孫の階層が1つ増えるごとに大きくする。
   2. 根は、全セルを含み意味を持たないため、描かない。
4. **色**: 各リージョンの色は、既存の色分けと同じ色（同じIDは常に同じ色）を使う。親子で色が衝突した場合は、間隔の差で区別する。兄弟リージョンなど、祖先と子孫の関係にないリージョンの領域が重なる場合は、深さの浅い順、同じ深さならリージョンIDの順に重ねて描く。
5. **名前**: 各リージョンの名前を、外周の左上に小さく表示する（色のみに依存させない）。凡例は従来どおり表示する。
6. **対象のセル**: 表示中のセルだけを対象とする。表示フィルタで非表示のセルや、リージョンごと非表示のセルは、領域に含めない。
7. **モードの保存**: モードの状態は、`.cde` にも前回セッションにも**保存しない**。起動時はオフである。他の表示状態（色分け・表示フィルタ）と同じ扱いとする。
8. 画像出力には、画面の表示のとおり含める。
