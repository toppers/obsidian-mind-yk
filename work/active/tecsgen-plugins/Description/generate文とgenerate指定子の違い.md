Ruby版tecsgenの generate文　と generate 指定子　の違いを教えて

  Ran 2 shell commands

どちらも最後は同じ apply_plugin に行き着きます。違うのは書く場所、呼び出されるタイミング、指定できる回数です。

構文

呼び出されるタイミング

指定子は、対象の定義を読み終える時点で呼ばれます。@generate に保存しておき、定義の最後に celltype_plugin / cell_plugin / signature_plugin を呼ぶ流れです。

┌───────────┬──────────────────┐
│   対象    │   呼び出し箇所   │
├───────────┼──────────────────┤
│ celltype  │ celltype.rb:241  │
├───────────┼──────────────────┤
│ cell      │ cell.rb:527      │
├───────────┼──────────────────┤
│ signature │ signature.rb:123 │
└───────────┴──────────────────┘

文は、Generate#initialize(generate.rb:49)が Namespace.find で対象を探し、見つかった対象の apply_plugin を呼びます。そのため、対象は文より前に定義されている必要があります。見つからないと S9999 generate: signature '...' not found になります。

回数

- 指定子:同じ対象に付けられるのは1つだけです。celltype は S1014、cell は S1163、signature は S9999 で重複エラーになります。
- 文:同じ対象に何回でも書けます。celltype.rb の @generate_list に、適用した順で積まれます。

使い分けの目安

- 指定子:自分が定義する対象に付けるときに使います。cell では、prototype との併用がエラーになります。
- 文:別ファイルで定義された対象や、他のプラグインが生成した CDL の対象に後から付けたいときに使います。プラグイン内部の自動発行は、ほぼすべて文の形です。
  - 例:HRPSVCThroughPlugin.rb:114 と 153
  - 例:MrubyInfoBridgePlugin の generate(MrubyInfoBridgeSignaturePlugin, ...)

補足

- 既存セルへの再適用:celltype に対して apply_plugin が呼ばれたとき、その時点で既に存在するセルには new_cell が順に呼ばれます(celltypeModule.rb:78)。指定子でも文でも同じです。そのため、文で後から付けた場合も、既存セルが取りこぼされません。
- 第2引数の意味:指定子の第2引数は plugin_arg(オプション文字列)です。文の第2引数は対象のパスで、オプション文字列は第3引数です。

実際に tecsgen を実行しての確認はしていません。上記は文法規則と、celltypeModule.rb、cell.rb、signature.rb、generate.rb の該当箇所を読んだ結果です。
