# 4C. ファイル別保存契約

[[TECSCDE-DT-EL内部仕様 - 04B CDLパーサ設計]]4B.6の詳細を分離した節です。[[TECSCDE-DT-EL内部仕様]]の保存設計として参照します。

**保存契約の統一（2026-11-07、監査#1）**: [[TECSCDE-DT外部仕様 - 05 ファイル操作]]5.4節と[[TECSCDE-DT-EL内部仕様 - 07C 読み込み経路の統合]]7.7節に従い、主ファイルも追加読み込みファイルも同じ定義元による選別を行う。以下は保存契約の更新であり、実装の適合確認済みを意味しない。

- **`serializeSource(doc, sourceKey)`**: 主ファイルかどうかにかかわらず、`cell.editable && cell.locale === sourceKey`のセルだけを選別して書く。対象ソースの`sourceTemplate`を使い、テンプレートがない場合も選別範囲を広げない。主ファイルだけ全編集可能セルを出力する分岐は設けない。`tecscde`ブロックの既知レイアウトは、選別したセル・ポート・結合のバーから作り直す。各階層の未知キーは対象ソースと要素の対応に従って引き継ぎ、削除済み要素を復活させない。再構成は未知フィールド全消去を意味しない（監査#33）。主ファイルの`tecsgen`ブロックは既存の版・保存時刻・`directImport`更新規則に従い、それ以外のソースの`tecsgen`ブロックは変えない。
- **`serialize(doc, now)`**: 主ファイル用の入口として残す場合も、主ファイルの`sourceKey`を確定し、`serializeSource`と同じ選別規則を適用する。選別後のセルを名前順に並べ（決定性のため）、そのソースの`import`原文、`cell`ブロック、`tool_info`を出力する。他ソースのセル・属性・結合を主ファイルへ集約する入口にはしない。
- **テンプレート方式**（`serializeFromTemplate`）: 対象ソースの元テキストのセル範囲を削除し、選別したセルだけを各リージョン（スコープ）の末尾へ挿入する。コメントは`leadingText`としてセルについていく。`tool_info`は既存の位置で置換し、無ければ先頭（`tecsgen`）または末尾（`tecscde`）に足す。編集は位置の降順に適用する。他ソースのテンプレートや複合定義を持ち込まない。
- **所属先と保存先パス**: 新規・貼り付けセルの定義元は7.7節の規則で割り当て、読み込み済みの他ソースのセルを定義元未設定として主ファイルへ取り込まない。「名前を付けて保存」でも、選別には移動先の新パスではなく保存対象ソースの`sourceKey`を使う。出力先パスの指定を、複数ソースの内容を結合する指示とは扱わない。
- **保存後の検査**: 書いた結果をもう一度`build`して検証し、不整合なら**例外**を投げる（診断ではない）: 対象ソースの複合定義の名前・原文が変わった、構文エラーが出た、選別した保存対象のセル数・識別が変わった、セルの所属リージョンが復元できない。読み込んだ全ソースのセル数とは比較しない。保存前にも、リージョン所属の不整合、同名セル、保存先リージョンが対象ソースに無いことを例外にする。
- **結合の書き出し**: 呼び口側のセルが選別した保存対象に含まれる結合だけを、CDLの結合代入と`joinList`へ出す（外部仕様5.4.1）。受け口側が別ソースでも結合参照は保持するが、その相手セルの定義は出力しない。別ソースの呼び口から入る結合は、その別ソースの保存対象とする。

**契約の検証条件**: 主ファイルAと追加読み込みファイルBの両方に編集可能セルがある場合、Aの出力にBのセル定義がなく、Bの出力にAのセル定義がないことを確認する。AからBへの結合はAにだけ書かれ、受け口セルBの定義は複製されないことも確認する。新規・貼り付けセルは割り当てた定義元だけに現れ、読み取り専用・Plugin生成セルはどちらにも保存されないことを確認する。`serialize`、テンプレートなし、名前を付けて保存の各経路にも同じ条件を適用する。

保存対象ごとの保存済み状態と非同期保存の結果反映は[[TECSCDE-DT-EL内部仕様 - 07J 保存チェックポイントと未保存判定|7J]]に従う（2026-11-08、監査#21）。書き込み成功したソースの実保存状態だけをbaselineへ採用し、別ソースの失敗や保存中の新編集をcleanにしない。保存注記の時刻を未保存比較へ混ぜない。
