## 11. 用語集

本節は第1〜10章で用いた用語のうち、TECSCDE 特有の意味を持つもの、または本仕様の理解に直接関わるものを掲載する。CDL 言語一般の用語は [[work/active/tecsgen/tecsgen外部仕様 - 10 用語集#10. 用語集|tecsgen外部仕様の用語集]] を正とし、本節では TECSCDE の文脈での用法に限って再掲・補足する。

| 用語 | 定義 |
|------|------|
| TCD | TECS Component Diagram。TECS コンポーネント構成を視覚的に表現する図（1.1） |
| TECSCDE | TECS Component Diagram Editor。CDL とコンポーネント図（TCD）を双方向変換する設計環境。コード生成は行わず、tecsgen の前段に位置する（1.2） |
| CDL | Component Description Language。TECS のコンポーネント記述言語 |
| CDE（`.cde`） | TECSCDE の保存形式。拡張子は独自だが中身は CDL そのものであり、`__tool_info__` ブロックにツール情報とレイアウト情報を同居させる（5.1.1） |
| セル | コンポーネントのインスタンス（`TmCell`）。矩形として描かれる（4.1） |
| セルタイプ | コンポーネントの型定義。TECSCDE のモデルには独立した図要素として存在せず、セルが参照するのみ（4.2.1） |
| 呼び口（Call Port） | 機能を要求するポート。結合は最大1本まで（4.3） |
| 受け口（Entry Port） | 機能を提供するポート。呼び口と異なり結合を複数持てる（4.4） |
| シグニチャ | 呼び口・受け口のインターフェース定義。結合の可否はシグニチャの一致で判定する（4.5） |
| 結合（Join） | 呼び口1つと受け口1つを結ぶ関係。水平・垂直の結合バーの列（折れ線）として描かれる（4.6） |
| 結合バー（Join Bar） | 結合の折れ線を構成する水平／垂直の線分（`HBar`／`VBar`）。斜線は用いない（4.6） |
| 複合セルタイプ（Composite） | 複数のセルを内包するセルタイプ。CDL 言語・tecsgen コアには存在するが、TECSCDE のモデルには対応する概念が一切ない（4.7） |
| リージョン（Region） | セルの所属を表す木構造。ユーザが選択して作るグループではなく、CDL/tecsgen のネームスペース階層をそのまま反映する（4.9） |
| ネームスペース | リージョンの識別子（`::` 区切り）。独立した図要素ではなく、リージョンに統合されている（4.8） |
| 属性（Attribute） | セルが持つ「属性名 → 式」のペア。図上には表示せず、プロパティパネルで編集する（4.1.1、6.5） |
| 配列ポート（Array Port） | 添字を持つ呼び口・受け口。要素の挿入・削除に制約（固定長拒否、添字0削除不可）を持つ（6.1、6.3） |
| グリッド（ALIGN） | 座標を丸める基準値。1.0 mm に固定され、変更不可（3.2.1、7.2） |
| locale | セルの定義元ファイルと行を指す情報。編集可否の判定基準となる（10.2.1） |
| 編集可能／編集不可（read only） | セルの `locale` が編集対象ファイル自身かどうかで決まる区分。編集不可のセルは削除・変更できない（10.2） |
| 参照専用ファイル（兄弟ファイル） | 編集対象ファイルと一緒に指定されるが、それ自体は編集しないファイル。現行版では起動時のコマンドライン引数、JS 版では複数ファイル選択時の非対象ファイルに相当する（8.1.2） |
| `__tool_info__` | CDL 中に埋め込まれる TECSCDE 専用のブロック。tecsgen 起動情報（`base_dir` 等）とレイアウト情報の2種を保持する（5.1.1） |
| `direct_import` | `__tool_info__("tecsgen")` に記録される、コマンドライン引数として直接指定された参照専用ファイル（兄弟ファイル）の一覧（8.2.1） |
| 整合性チェック | 図と CDL の差分・未解決要素（セルタイプ未解決・結合先不在・複合セルタイプ・レイアウト不整合等）を1件のレポートとして集約表示する、JS 版の新規機能（8.3.2） |
