## 3. 画面構成

第2章で JS 版の実行形態をブラウザ単体と定めたため、本章で規定する画面はすべて**単一の HTML ドキュメント内の領域**である。現行版が採る複数のトップレベルウィンドウ（メインウィンドウ＋パレットウィンドウ）による構成は用いない。

本章で示す現行版の事実は、tecscde V0.5.1 のソース（`cdelib/tview.rb`・`cdelib/palette.rb`・`glade/*.glade`）および `README.txt` に基づく。

### 3.1 メインウィンドウ

#### 3.1.1 現行版（Ruby/GTK 版）の構成

| 項目 | 内容 |
|------|------|
| ウィンドウ種別 | `Gtk::Window`（TOPLEVEL） |
| タイトル | `TECSCDE - TECS Component Diagram Editor` |
| 既定サイズ | 900 × 600 px |
| 内部構成 | 垂直2分割。上＝スクロール可能なキャンバス、下＝表示制御バー（高さ 50 px） |
| 表示制御バー | 「Emphasize Cell Name」トグルボタン、「Color by Region」チェックボックス、ズームスライダ |
| メニューバー | なし |
| ステータスバー | なし |

パレットは別のトップレベルウィンドウであり、メインウィンドウを親（transient）とし、タスクバー・ページャに出さない設定で表示される。すなわち現行版の操作系は、メニューではなく**常時表示のパレットウィンドウ**に集約されている。

#### 3.1.2 JS 版の画面領域

```
┌──────────────────────────────────────────────┐
│ ツールバー（ファイル・選択モード・編集）        │
├───────────────────────────┬──────────────────┤
│                           │ セルタイプ一覧     │
│   キャンバス（3.2）        │  （3.3）          │
│                           ├──────────────────┤
│                           │ プロパティ         │
│                           │  （3.4）          │
├───────────────────────────┴──────────────────┤
│ 表示制御バー（強調表示・色分け・倍率）          │
├──────────────────────────────────────────────┤
│ ステータス表示                                 │
└──────────────────────────────────────────────┘
```

| 領域 | 役割 | 現行版の対応 |
|------|------|------------|
| ツールバー | 保存・エクスポート、選択モード、アンドゥ／リドゥ | パレットの File / Select Mode / Edit フレーム |
| キャンバス | 図の表示・編集 | メインウィンドウのキャンバス |
| セルタイプ一覧 | 配置可能なセルタイプの選択 | パレットの celltypes フレーム |
| プロパティ | 選択中オブジェクトの表示・編集 | パレットの cell フレーム |
| 表示制御バー | 強調表示・色分け・表示倍率（7章） | メインウィンドウ下端の表示制御バー |
| ステータス表示 | 現在のモード、座標、エラー件数 | 相当機能なし（新規） |

規定：

- すべての領域を単一のドキュメント内に配置し、OS ウィンドウを追加しない。
- ツールバー・サイドパネル・ステータス表示は表示／非表示を切り替えられる。キャンバスは常に表示する。
- 表示領域の大きさが変化した場合、キャンバス領域が伸縮する。サイドパネルの幅は保持する。

### 3.2 キャンバス（図描画エリア）

#### 3.2.1 座標系と用紙

| 項目 | 現行版 | JS 版 |
|------|--------|-------|
| モデル座標の単位 | mm | mm（同一） |
| 用紙サイズ | A4横 277×190 / A3横 400×277 / A2横 574×400（mm・余白 10 mm を除いた値）。既定は A3横 | 同じ3種を規定。既定は A3横 |
| 用紙サイズの変更 | UI からは不可（CDE ファイルの直接編集が必要） | UI から選択可能とする |
| グリッド | 1.0 mm | 1.0 mm（同一） |
| mm→画素換算 | 96 DPI 基準 × 表示倍率 | 同一。CSS の px は 1/96 in と定義されるため、96 DPI 換算は CSS 単位系とそのまま一致する |
| 表示倍率 | 5 %〜200 %、既定 100 %、整数値のスライダ | 同一範囲を既定とする |

用紙サイズの変更を UI から可能にする点は、現行版の制限（README に「V0.5.\* では CDE ファイルを直接編集する必要があります」と明記）を解消するための拡張である。

#### 3.2.2 描画方式

現行版は、オフスクリーンの Pixmap に図全体を描画し、それをウィンドウへ転送したうえで、選択中オブジェクトの強調表示のみをウィンドウへ直接描く二段構成を採る。再描画のたびに図全体を描き直す。

JS 版は 2.3 で定めたとおり **SVG** を用いる。

- キャンバスのルートを単一の `<svg>` 要素とし、図要素（セル・ポート・結合線・文字列）をその子要素として保持する。
- 変更は該当要素の属性更新で反映し、図全体の再描画は行わない。オフスクリーンバッファに相当する機構を持たない。
- 選択中オブジェクトの強調表示は最前面の専用グループに描画し、図本体の要素を変更しない。

#### 3.2.3 スクロールと表示範囲

キャンバスの論理サイズは「用紙サイズ × 表示倍率」で決まる。表示領域より大きい場合はスクロールする。表示倍率の変更時は論理サイズを再計算し、スクロール位置を保つ。

### 3.3 パレット（要素選択パネル）

#### 3.3.1 現行版の構成

パレットウィンドウ（タイトル `TECSCDE Palette`）は6つのフレームからなる。

| フレーム | 要素 | 機能 |
|---------|------|------|
| File | Save ボタン、Export ボタン | CDE ファイルの保存、エクスポート |
| Select Mode | Select Object / New Cell の2トグルボタン | 排他。一方を押すと他方が解除される |
| Edit | Undo ボタン、Redo ボタン | Redo は V0.5.1 では常時無効（コード上で明示的に無効化されている） |
| celltypes | ツリービュー（150 × 150 px） | 配置可能なセルタイプの一覧 |
| cell | 名前欄、リージョン欄、属性ツリービュー | 選択中セルのプロパティ（3.4 参照） |
| （無題） | quit ボタン | 終了 |

#### 3.3.2 JS 版の規定

- 選択モードは「選択」「セル新規作成」の2状態を持ち、排他とする。**いずれか一方が常に選択されている状態**とし、現行版が持つ「どちらも非選択」の初期状態は設けない。既定は「選択」とする。
- セルタイプ一覧は、読み込んだ CDL 由来のセルタイプを列挙する。ここで選択したセルタイプが、セル新規作成時の対象となる。
- Redo は 6.6 で規定する。現行版の無効化状態を仕様として引き継がない。
- 終了ボタンは設けない。ブラウザのタブ／ウィンドウを閉じる操作が終了操作に相当する。未保存時の扱いは 5.3 で規定する（現行版は README に「CDE ファイルの未保存でも終了してしまう」と既知の問題として記載されている）。

### 3.4 プロパティパネル

#### 3.4.1 現行版の構成

現行版は独立したプロパティパネルを持たず、パレット内の cell フレームがその役割を担う。対象はセルのみで、ポート・結合を対象とする表示はない。

| 要素 | 内容 |
|------|------|
| name | セル名の入力欄。Enter キーまたはフォーカス離脱で確定 |
| region | 所属リージョンの表示欄。V0.5.1 では表示のみで、変更処理は無効化されている |
| 属性一覧 | セルの属性を並べるツリービュー |
| 編集可否の表示 | CDL 由来のセルは編集不可。フレーム見出しが `cell property (read only)` に変わる |

編集可否の区別（**CDL ファイル由来のセルは削除・変更できず、CDE ファイル由来のセルのみ編集できる**）は現行版の中心的な制約であり、JS 版でも維持する。詳細は 6章および 10章で規定する。

#### 3.4.2 JS 版の規定

- 選択中のオブジェクト（セル／呼び口／受け口／結合）に応じて表示内容を切り替える。対象をセルに限定しない点が現行版との差である。
- 複数選択時は、共通して編集できる項目のみを表示する。
- 編集不可のオブジェクトは、入力欄を読み取り専用にしたうえで、その旨を文言で示す。**色のみによる区別は行わない**（現行版は文字色で区別を試みているが、コード中に機能していない旨が記録されている）。

### 3.5 ファイルブラウザ / ナビゲータ

**ファイルブラウザは提供しない。** 現行版もこれを持たず、編集対象は起動時のコマンドライン引数（tecsgen 互換の引数群、または CDE ファイル）で決まり、実行中に別のファイルを開く経路はない。JS 版では 2.3 で定めたとおりファイル入出力がユーザ操作を伴う経路に限られ、ローカルのディレクトリツリーを列挙できないため、そもそも実現できない。ファイルの選択方法は 5.2 で規定する。

**ナビゲータ（図全体の縮小表示）は提供する。** 既定の用紙サイズが A3横（400 × 277 mm）であり、100 % 表示では表示領域に収まらないことが通常であるため、全体における現在位置を示す手段を必要とする。本章では画面上の位置のみを定め、キャンバス領域の隅に重ねて配置し、表示／非表示を切り替えられるものとする。動作は 7.1 で規定する。

### 3.6 ダイアログ

#### 3.6.1 現行版の状況

現行版には5種のダイアログが glade ファイルとして定義されているが、**V0.5.1 の制御コードからはいずれも起動されない**。

| glade ファイル | ダイアログ | V0.5.1 での到達性 |
|---------------|-----------|------------------|
| `tecscde-celltype.glade` | Celltype Property（セルタイプ定義・受け口・呼び口・属性・FACTORY の編集） | 参照元は試作スクリプト `glade/test-*.rb` のみ |
| `tecscde-cell-property.glade` | cell（名前・セルタイプ・プロパティ・説明） | 同上 |
| `tecscde-celltype-property.glade` | celltype（名前・プロパティ・説明） | 同上 |
| `tecscde-export.glade` | Export（パス・ファイル名・ファイル種別） | 同上。実際のエクスポート処理は拡張子 `.pdf` 固定で、このダイアログを経由しない |
| `tecscde-cell-plugin.glade` | Cell Plugin（プラグイン一覧・オプション文字列・説明） | 起動用メソッドは存在するが、呼び出し元がない |

したがって V0.5.1 で実際に表示される UI は、メインウィンドウ・パレットウィンドウ・セル名のインプレース編集欄・メッセージボックスの4つに限られる。上記の glade 群は**実装に至らなかった機能の設計意図の記録**として扱い、JS 版の仕様を組み立てる際の入力とする。

#### 3.6.2 JS 版で規定するダイアログ

| ダイアログ | 契機 | 規定箇所 |
|-----------|------|---------|
| エクスポート | ツールバーのエクスポート操作 | 5.5 |
| セルのプロパティ | セル選択後の詳細表示操作 | 6.5 |
| セルタイプのプロパティ | セルタイプ一覧からの詳細表示操作 | 4.2 |
| メッセージ（エラー・警告・確認） | 9章の各エラー、および 5.3 の未保存確認 | 9.2 |

ダイアログはモーダルとし、表示中はキャンバス上の編集操作を受け付けない。ブラウザ標準の `alert` / `confirm` / `prompt` は用いない。表示内容を制御できず、9.2 で規定するメッセージ形式を満たせないためである。

### 3.7 モードとカーソル

現行版は編集状態をモードとサブモードの2段で保持する。この状態はどの画面要素にも表示されず、カーソル形状とボタンの押下状態からのみ判別できる。

| 区分 | 値 |
|------|-----|
| モード | 未選択 / セル新規作成 / 選択 |
| サブモード | なし / 結合中 / 範囲選択中 / セル・結合線の移動中 / 呼び口の移動中 / 受け口の移動中 / セル名編集中 |

カーソル形状は4種で、ポインタ直下のオブジェクトと現在のサブモードから決まる。

| 状況 | 現行版のカーソル | JS 版 |
|------|----------------|-------|
| 通常 | 左上向き矢印 | 既定のポインタ |
| 呼び口の上 | 左向き矢印 | 結合を開始できることを示す形状 |
| 結合操作中 | ドット | 結合中であることを示す形状 |
| 結合先として有効な受け口の上 | 円 | 結合可能であることを示す形状 |

規定：

- 「結合先として有効」の判定は、シグニチャが一致する受け口であることとする（現行版と同一。6.4 で規定）。
- カーソル形状の具体は実装に委ね、本仕様では上記4状態が視覚的に区別できることのみを要求する。
- 現在のモードは 3.1.2 のステータス表示に文字で示す。カーソル形状のみに依存させない。
