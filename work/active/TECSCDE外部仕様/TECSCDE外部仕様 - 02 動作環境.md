## 2. 動作環境

本仕様が対象とするのは JS 版（フレームワーク非依存）である。ここでは現行の Ruby/GTK 版を出発点として示したうえで、JS 版の動作環境を定める。

### 2.1 現行版（Ruby/GTK 版）

既存実装 tecscde V0.5.1（2016-05-08、大山博司）の動作環境。JS 版が置き換える対象であり、移行時の互換性判断の基準となる。

| 項目 | 内容 |
|------|------|
| 実装言語 | Ruby |
| 動作確認 OS | Linux（X Window 前提）／ Windows 7 SP1 64bit（MinGW 版・ランタイムは 32bit） |
| 依存ライブラリ / ランタイム | Ruby 1.9 以降、Ruby Gtk2（`gem install gtk2`）。Windows は `tecscde-MinGW-RT` パッケージを別途展開 |
| ツールバージョン | tecscde V0.5.1 が tecsgen V1.3.1.0 以降に対応。Windows 版パッケージは tecsgen V1.3.1.7 を前提 |

現行版はコンソールから起動する GUI ツールであり、起動方法は CDL ファイルを入力とする方式と CDE ファイルを入力とする方式の 2 通りがある。GTK と X Window への依存が、プラットフォームごとの導入手順の差（MinGW ランタイムの同梱、cygwin 上でのフォント・ディスプレイ問題）を生んでいる。

### 2.2 JS 版（フレームワーク非依存）

| 項目 | 内容 |
|------|------|
| 実装言語 | JavaScript（ES2020 以降） |
| 動作確認 OS | OS 非依存。対象ブラウザが動作する環境であれば区別しない |
| 依存ライブラリ / ランタイム | なし。DOM・SVG の標準 API のみを用い、UI フレームワーク・描画ライブラリ・ビルドツールを前提としない |
| ツールバージョン | tecsgen V1.3.1.0 以降が受理する CDL を入出力対象とする |

実行形態はブラウザ単体（ローカル）である。サーバ側の処理系を持たず、すべての図の構築・CDL の解析と生成をブラウザ内で完結させる。これにより 2.1 に挙げたプラットフォーム依存（GTK ランタイムの配布、X Window の前提、32bit/64bit の使い分け）が仕様上消滅する。

「フレームワーク非依存」とは、本仕様の範囲において特定の UI フレームワークに依存する記述を行わないことを指す。フレームワーク依存版は本仕様を満たす実装のひとつとして別途規定する（[[TECS開発]] 参照）。

### 2.3 ブラウザ単体構成に由来する制約

サーバ処理系を持たない構成から、以下が仕様上の制約として導かれる。

- **ファイル入出力はブラウザの許可範囲に限られる。** ローカルの `.cdl` を直接読み書きする経路はユーザ操作を伴うものに限定される。具体的な操作方式は「5. ファイル操作」で規定する。
- **tecsgen を直接起動できない。** 現行版と異なりコード生成をツール内から呼び出す経路を持たないため、tecsgen との連携は生成した `.cdl` の受け渡しによる。「8.4 tecsgen との連携」はこの前提で規定する。
- **図の描画は SVG を用いる。** Canvas ではなく SVG を採ることで、要素の選択・ヒットテスト・部分更新を DOM の機構で扱え、画像エクスポート（5.5）で SVG をそのまま出力できる。
