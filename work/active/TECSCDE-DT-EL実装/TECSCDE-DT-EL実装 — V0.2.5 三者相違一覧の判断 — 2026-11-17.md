# TECSCDE-DT-EL実装 — V0.2.5 三者相違一覧の判断 — 2026-11-17

[[TECSCDE-DT-EL実装]]の Action Items から分離した（2026-11-17、25KB閾値）。三者相違一覧（[[TECSCDE-DT-EL実装 — V0.2.5 三者相違一覧 — 2026-11-16|索引]]）に対する判断と、V0.2.6 の実装の完了条件。以下は原文のまま。

## 判断と完了条件

- [ ] [[work/active/TECSCDE-DT-EL実装/TECSCDE-DT-EL実装 — V0.2.5 三者相違一覧 — 2026-11-16|V0.2.5 三者相違一覧]]の判断（2026-11-17、ユーザー）。仕様の追随と、v0.2.6 の範囲づくりの前提。**仕様側は 2026-11-17 に反映済み。ソース側の変更は [[TECSCDE-DT-EL実装 — V0.2.6 実装計画 — 2026-11-17|V0.2.6 実装計画]] へ整理**（ソースはまだ変えていない）
  - 1-19（タグとアプリ版）: **ソースに寄せる**。リリースタグは手で打つもので、`package.json` の版との一致を機械では保証しない。外部 02 2.5.5「リリースタグは、すべてこの版から決まる」を、実態に合わせて直す
  - 2-5（メニューバー・File > Exit）: 外部 03 3.1 に「メニューバーを追加した場合は」という注釈を付ける。今のソースはメニューバーが無い（終了は OS の閉じるボタンだけ）
  - 8-20（`-k`）: **`.tecsgen-opts` に `-k`／`--kcode` が書かれていれば、その値を優先し、書かれていないときにだけ `-k utf8` を付ける**（2026-11-17、ユーザー決定。Generate・コマンドコピー・Plugin 取り込みのすべて。当初の「常に付ける」から改めた）。Plugin 取り込みは、この規則を実装済み（`tecsgen-runner.ts`）。Generate・コピーは、`command-builder.ts` が opts の `-k` を引き継がず、常に `-k utf8` を付けるため、**ソースの変更を v0.2.6 の範囲に入れる**（opts の `-k` を読んで渡し、あれば `-k utf8` を付けない）。外部仕様 8.4.2 に規則を書いた
  - 7-9（倍率スライダ・グリッド・ナビゲータの置き場所）: **ソースに寄せる**。外部仕様に、ソースの置き場所（表示設定グループの外）を書く
  - 7-10（倍率の刻み）: **倍率は 5% 刻みの整数値に丸める**。実装は「Ctrl+／Ctrl−／ホイールの1回の操作で 5% ずつ増減する」（範囲 5%〜200%、2026-11-17 確認済み）。×1.1 の後に丸める方式は、5% のとき 5.5→5 に戻って進まなくなるため採らない。仕様だけでなく、ソースの変更を含む（今は 110%→121%→133.1% と整数でない値になる）
  - 7-11（グリッド線）: **ソースに寄せる**。線の間隔 10 mm・線幅 0.5 px を、仕様に書く（グリッド単位は 1.0 mm のまま）
  - 7-9 の付随点（ラベルが英語の「Reset Rate」、「グリッド」「ナビゲータ」がオン・オフを示さない）は、置き場所の決定の範囲外として、今回は扱わない（2026-11-17 確認済み）
  - 8-4（`.tecsgen-opts` の `-c`／`--cpp`）: **案A（ソースを仕様に合わせる）を採用**（2026-11-17）。opts の `cpp` を `OpenResult` に載せて、`import_C` の解決（Ctrl+クリックの追加を含む）にも使う。opts と CDL の `__tool_info__` の `cpp` が両方あるときは opts を優先する（Generate の現状と同じ。実際の tecsgen の挙動は TBC）。値は引数込みの完全なコマンドとして扱い、`cppArgs` は付けない。**v0.2.6 の範囲に入れる**。仕様（外部「Cプリプロセッサ設定と失敗詳細(V0.2.1用)」2.3、外部 02 2.4、内部 09E）は、同日に直した
  - 1-6（`cdlFilesRoot` の設定 API）: **統合 API 案を採用**（2026-11-17）。`getToolSettings`・`updateToolSettings(patch)` に対象ディレクトリを含め、成否と revision を返す。専用 IPC（`settings:getCdlFilesRoot`・`setCdlFilesRoot`・`chooseCdlFilesRoot`）は統合へ移す。**v0.2.6 の範囲に入れる**。内部 09D 9D.5 に、実装が未対応である旨を追記した
  - 1-11（対象プラグインの付表）: 外部 8.5 と内部 09D 9D.6・11 を、**実装に合わせて更新した**（付表は `MrubyBridgePlugin`・`MrubyBridgeCellPlugin` の2件、tecsgen 1.9.1、基準データ55ファイルと完全一致。2026-11-17）
  - 1-16（Node API の誤 import の検出）: **ソース側を強化する**（2026-11-17）。dependency-cruiser で、`renderer/` から `node:*` と Node 組込みモジュールへの import を禁止し、`tsconfig.renderer.json` の `lib` を絞って `@types/node` を型検査から外す。**v0.2.6 の範囲に入れる**。内部 10 10.3 に、現行との差と強化の方針を追記した
  - 7-16（節番号・既定の記述のずれ）: 仕様側は直した（TS 06 6.3 の節番号、DT-EL 06 の注記。2026-11-17）。**ソースのコメントの誤りの訂正を、v0.2.6 の範囲に入れる**（コメントだけの変更。`navigator.ts:6,35`・`navigator-panel.ts:1-3,18,36` が引く「7.3.2」→「7.1.2」、`display-filters.ts:28`・`index.html:768` が引く「7.3.x」→「7.5.x」、`view-state.ts:3` の「完全に同一、変更なし」の削除、`view-state.ts:89` の `resetZoom` の説明。あわせて 9-17 の3か所: `clipboard-gateway.ts:1-3`、`collector.ts:3`、`diagnostics-panel.ts:1-5`）
  - **未決**: 6-22（Backspace で削除）。「メニューバーを追加した場合は」の注釈は 2-5 向けで、6-22 には当てはまらないため、2-5 だけに適用した。6-22 は、仕様に Backspace を足すか、ソースから外すかを決める（この切り分けは 2026-11-17 に確認済み。6-22 は未決のまま）
